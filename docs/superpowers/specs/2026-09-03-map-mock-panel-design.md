# OPC 政策地图首个可运行切片设计

## 目标

在空目录中建立可运行的 Next.js 应用，完成“中国省级地图 → 点击地区 → 调用 Mock API → 右侧展示政策”的最小闭环。

## 本轮范围

- 首页包含品牌页头、简要统计、ECharts 中国地图和右侧政策面板。
- 地图支持省份悬停提示、点击选中、高亮、滚轮缩放和拖拽。
- 重庆、四川、广东、浙江、北京、上海各提供 3 条明确标注为 `DEMO DATA` 的虚构演示政策。
- 政策不写在 React 组件中；统一存放在独立数据模块，通过 `GET /api/policies?province=` 返回。
- 右侧面板包含地区信息、分类统计、政策卡片、加载态、错误态和空状态。
- 桌面端左右布局；窄屏地图在上、政策列表在下。
- 本轮不接入 Supabase，不实现后台、搜索和完整筛选。

## 架构

`app/page.tsx` 保持为 Server Component，只组合页面静态结构与交互入口。`PolicyExplorer` 是最小客户端状态容器，负责选中省份和请求状态；`ChinaMap` 只接收省份统计并发出选择事件；`PolicyDrawer` 只渲染查询结果。Mock 数据和筛选函数位于 `data/` 与 `lib/`，Route Handler 调用同一查询函数，下一阶段可在不改组件接口的情况下将查询实现替换为 Supabase。

## 数据契约

`Policy` 包含标题、地区、分类、标签、发布日期、摘要、亮点、适用对象、来源名称、来源链接以及 `isDemo`。API 返回 `{ data: Policy[], meta: { province, total } }`；缺少省份参数时返回全部示例政策，未知省份返回空数组。

## 地图数据边界

中国省级 GeoJSON 作为独立静态资源保存于 `public/maps/china-provinces.geojson`，由地图组件在初始化时加载并注册。资源文件顶部无法携带注释，因此在项目说明中标明其仅用于开发演示，正式上线前必须替换为经过合规审查的数据源。

## 视觉与交互

采用白色与浅蓝灰背景、深蓝文本、克制的蓝色强调，不使用大面积渐变和厚重阴影。地图按政策数量分级着色，Tooltip 同时给出总数和主要分类数量。可点击元素具有清晰的悬停、键盘焦点和不少于 44px 的触控区域；动效限制在 150–250ms，并尊重减少动态效果设置。
